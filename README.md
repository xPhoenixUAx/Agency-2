# SIGNAL — Google-inspired agency pack

**Реалізація:** готовий сайт знаходиться в `web/`. Запуск: `php -S 127.0.0.1:8763 -t web`.
Інструкції — [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md), результати перевірок — [docs/IMPLEMENTATION-VALIDATION.md](docs/IMPLEMENTATION-VALIDATION.md).
Нижче збережено опис початкового паку.

Пак референсів та інструкцій для створення сайту Google Ads Performance Agency у Codex.
Затверджений напрям: білий фон, чотири кольорові акценти, округлі картки, легка графіка пошуку й результатів.

## Що всередині

- **5 основних сторінок:** Home, Google Ads Management, Tracking & Automation, Case Studies, Free Audit.
- **20 окремих PNG:** Desktop і Tablet для кожної сторінки; Mobile A і Mobile B — верх та продовження тієї самої сторінки.
- **5 посекційних MD** зі змістом, структурою HTML, поведінкою й адаптацією.
- **15 окремих MD за пристроями** з порядком блоків та перевірками.
- Спільна дизайн-система, компоненти, карта посилань, інструкції запуску та приймання.
- Робоча заготовка ребрендингу: `starter/config/site.json`, редактор `starter/rebrand.html`, JS застосування конфігурації.
- Заготовка форми з валідацією, станами, PHP-обробником, захистом CSRF та обмеженням частоти.
- SVG-іконки для реалізації, демонстраційна форма і технічні оболонки Privacy / Terms.

Це **пак для реалізації**, а не завершений п’ятисторінковий сайт. `starter/form-demo.html` дозволяє окремо перевіряти ребрендинг і форму. Фінальні сторінки створюються за інструкціями. Технічні оболонки Privacy / Terms потребують затвердженого тексту компанії; вони не входять до п’яти дизайнерських сторінок.

## З чого почати в Codex

1. Розпакувати архів у папку проєкту.
2. Відкрити цю папку у Codex або VS Code.
3. Передати Codex текст із `START-HERE-CODEX.md`.
4. Рухатися за `docs/IMPLEMENTATION-ORDER.md`, спочатку головна, потім спільні компоненти та внутрішні сторінки.

## Як читати референси

`references/01-home-desktop.png` — десктоп головної; `01-home-tablet.png` — планшет;
`01-home-mobile-a.png` та `01-home-mobile-b.png` — послідовні частини мобільної.
Аналогічно для сторінок 02–05. `references/index.html` — каталог для зручного перегляду.

1440 / 834 / 390 — **логічна ширина макета**, а не гарантія розміру PNG у пікселях.
Зображення передають композицію; точні розміри, тексти, переноси та функціональність беріть із MD.
Зокрема на 360px не зменшуйте весь макет трансформацією — перебудовуйте сітку.
Розбіжності з картинками перелічені в `docs/REFERENCE-NOTES.md`.

## Мінімальний стек

HTML5 / CSS3 / vanilla JavaScript modules. PHP 8.1+ на сервері форми.
Без React, Tailwind, Lenis, збірника та платних іконок.
Контейнер border-box не ширше 1440px; підтримуваний viewport від 360px.
Усі секрети — тільки в серверних налаштуваннях. `site.json` є публічним.
