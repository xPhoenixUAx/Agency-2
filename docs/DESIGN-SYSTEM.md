# Дизайн-система

## Характер і композиція

Google-inspired: легкий інтерфейс, білий фон, чіткі заголовки, чотири кольори як акценти.
SIGNAL — самостійний бренд. У логотипі текст компанії та чотири маленькі геометричні елементи.
Основні візуали: картка пошукового оголошення, продукт, кваліфікований контакт, результат,
конверсійний шлях. Замість стокових людей використовуйте власні SVG/UI-елементи.

## Розміри

| Параметр | Desktop ≥1200 | Tablet 768–1199 | Mobile 360–767 |
|---|---|---|---|
| container max-width, border-box | 1440 | 100% | 100% |
| gutter | 48 | 32 | 20 |
| робоча ширина на 1440/834/390 | 1344 | 770 | 350 |
| вертикальний padding секції | 88 | 64 | 48 |
| H1 | 64/69 | 48/54 | 36/40 |
| H2 | 40/48 | 34/41 | 28/34 |
| H3 | 22/29 | 22/29 | 20/26 |
| body | 18/29 | 17/27 | 16/26 |
| дрібний текст | 14/21 | 14/21 | 14/21 |
| gap | 24 | 20 | 16 |
| radius | 28 | 24 | 20 |
| padding картки | 32 | 24 | 20 |
| header height | 80 | 72 | 64 |
| input / CTA min-height | 48 | 48 | 48 |

На 360 робоча ширина = 320. Не встановлювати body min-width:360, що спричинило б скрол
на менших вікнах; 360 — мінімальна контрольна ширина. Нижче не ламаємо форму примусово.
Використовуйте minmax(0,1fr), min-width:0 та overflow-wrap:anywhere для email і довгих назв.
Нормальна висота карток визначається контентом. Рівні картки робити stretch у межах одного ряду.

## Шрифти

Візуальна ціль — дружній геометричний sans. Для реалізації рекомендується локальний
Roboto або інший шрифт із підтвердженою ліцензією; файли шрифту в пак не включені.
У starter є системний Arial/Helvetica fallback. Не копіюйте Google Sans із чужого сайту.
Font weights: body 400, кнопки 600, heading 600–700. Letter-spacing H1 -0.04em, H2 -0.025em.
Контент не залежить від завантаження зовнішнього шрифту.

## Графіка

SVG viewBox 0 0 64 64; icon shell 80 desktop, 64 tablet, 48–56 mobile.
Головні ілюстрації складаються з HTML-карток, SVG і псевдоелементів. Декор absolute
можливий лише всередині окремої illustration сцени з визначеною висотою.
Текст і CTA не позиціонувати absolute. На mobile ілюстрація завжди після CTA.
Службові сірі смужки всередині ілюстрацій декоративні, не підміна справжнього тексту.
Декор aria-hidden=true; змістовним ілюстраціям короткий alt або figcaption.

## Рух

Тільки opacity + translateY 12px; 240–400ms, stagger до 60ms. IntersectionObserver один раз.
Hover кнопки 160ms; максимум translateY(-2px). Не анімуйте числа як реальні результати.
prefers-reduced-motion та features.animations=false відключають рух. Ніяких Lenis і scroll hijacking.
Контент видимий за замовчуванням без JS; анімаційний клас додається тільки після ініціалізації.
