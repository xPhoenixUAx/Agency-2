Попередні 3D-сцени вилучено з web/. Звірка: `REFERENCE-ALIGNMENT.md`, порівняння: `artifacts/qa/reference-review.html`.
- `node tests/config-check.mjs`: валідний конфіг, ребрендинг, відхилення неправильних кольорів/email/списків/flags та небезпечних URL-схем.

- `python tests/static-check.py`: 8 HTML-сторінок, унікальні id, локальні файли й якірні посилання, відповідність label/control.
- `node tests/site-qa.cjs`: усі 5 основних сторінок × 9 ширин (360, 390, 768, 834, 1024, 1199, 1200, 1440, 1920) — 45 перевірок, горизонтального скролу немає. Скриншоти 390/834/1440 збережено в `artifacts/qa/`; зображення декодуються перед зняттям скриншотів.
- Клавіатура: відкриття меню Enter, закриття Escape/Close, повернення фокусу, закриття при переході на desktop; Services і FAQ. Блокування прокрутки фону.
- Фільтри Ecommerce/All, `aria-pressed`, повідомлення про кількість, три статті та empty state при вимкненні ілюстративних кейсів.
- Форма: required, неправильний email/URL, preselect Tracking & Analytics; серверні помилки біля полів, збереження даних після помилки, success лише за ok=true, очищення після підтвердження. Сценарії UI перевірено через перехоплення відповідей у тесті; production JS не імітує відправлення.
- Бренд змінюється на 7 публічних сторінках, довга назва працює на 360px, помилка конфігу показується та блокує submit; редактор експортує справжній JSON. FAQ і навігація доступні без JS.

- `python tests/php-integration.py`: справжній PHP endpoint, сесії та CSRF, 422, дозволені опції, honeypot, локальний успіх і ротація токена, replay 403, rate-limit 429, метод 405, payload 413, array input, URL, consent, UTF-8 byte limits, прострочений CSRF та повтор, зміна отримувача/списку через JSON, відмова транспорту 503.
- PHP API тести виконані в ізольованих копіях з `disable_functions=mail`; листи записувалися лише в тимчасові локальні outbox, які після тестів видалено. Зовнішні листи не надсилалися.

## Середовище й межі

- Windows, PHP 8.3.32, локальний Chrome через Playwright. Вбудований Browser Codex не вдалося автоматизувати: runtime посилається на відсутній `browser-service.mjs`. Для QA використано окремий локальний headless Chrome.
- Не виконано перевірки на фізичних iOS/Android-пристроях, Safari/Firefox та зі screen reader. Перевірки ширин — браузерна емуляція viewport.
- Реальний поштовий транспорт, домен, HTTPS та Inbox delivery не перевірялися: потрібне налаштування майбутнього хостингу та погоджена тестова скринька.
- Юридичні тексти не затверджено; Privacy/Terms зберігають явний Draft і noindex. Контактні дані example.com залишено як у вихідному конфігу.
- Кольори растрових зображень не змінюються разом із CSS-токенами. Деталі: `AGENCY-VISUALS.md`.
